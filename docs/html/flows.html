04 / CAD FLOWS

配置流程的共同方法

环境变量提供表单初值，Profile 保存可复用的业务设置，运行 TOML 记录当次执行输入。先分清这三层，再配置具体流程。

配置在哪里生效

配置位置负责什么修改后何时生效
shell / 项目 modulefile工具路径、规则候选、工艺目录、表单初值重新启动使用这些环境的 Virtuoso / SiCo 进程。
GUI ProfileDRC、LVS、RCE、LEF 的表单业务选项点击 Load 后回填表单；之后仍可手动调整。
运行目录中的 TOML该次任务最终输入、选项与运行路径对应 backend 读取该 TOML 时。
$SICO_HOME/etc/flow-defaults/CAD 统一维护的工具默认命令下一次生成命令时；一次生成中的各 corner 共用同一份快照。
Profile 与运行 TOML 用途不同。 表单的 Load 接受带元数据的 Profile；不能把任意 drc.toml、lvs.toml、rce.toml 或 lef.toml 当作 GUI Profile 载入。

配置工程与规则候选

Bash · 公共工程设置示例
export PROJECT_ROOT="/path/to/my/project"
export PDK_ROOT="/path/to/pdk"
export CDS_LIB="$PROJECT_ROOT/cds.lib"
export TECH_LAYER_MAP="$PDK_ROOT/stream/streamOut.map"
export CDL_HEADER_FILE="$PDK_ROOT/cdl/devices.cdl"

export DRC_DB_DIR="$PROJECT_ROOT/runs/drc"
export LVS_DB_DIR="$PROJECT_ROOT/runs/lvs"
export RCE_DB_DIR="$PROJECT_ROOT/runs/rce"
export DRC_FILE="default,$PDK_ROOT/pv/drc.cal"
export LVS_FILE="default,$PDK_ROOT/pv/lvs.cal"
export RCE_LVS_FILE="default,$PDK_ROOT/pv/lvs-rc.cal"

候选列表采用 显示名,路径;显示名,路径，整个值必须加引号。单个裸路径也可以使用。PROJECT_ROOT 和 PDK_ROOT 是示例里的路径前缀约定，不是 SiCo 自动发现的工艺设置。

保存与复用 Profile

  1. 在 flow 表单完成设置后，使用 Save As… 将 Profile 保存到项目配置目录。
  2. 下一次在 Config File 选择该文件并点击 Load。加载前会校验 flow 类型、版本和字段。
  3. 按本次设计修改库、cell、view 和输出路径，点击 Run；本次运行生成自己的 TOML，不覆盖 Profile。
TOML · Profile 标识，正文由 GUI 保存
[cad_config]
format = "sico-flow-profile"
version = 1
flow = "RCE"

flow 可为 DRC、LVS、RCE 或 LEF。这段仅展示标识，不是可执行的完整配置。可设置 DRC_CONFIG、LVS_CONFIG、RCE_CONFIG、LEF_CONFIG 预填路径。

Profile 的相对路径基于 Profile 所在目录，支持 $VAR 与 ${VAR}。Profile 中尚未定义的变量表达式可保留；实际运行前必须提供其非空值。路径表达式未经修改再次保存时会保留原文。

输出目录与执行主机

表单通常提供 Project Directory、Current Directory、Customize Directory。项目目录分别来自各 flow 的 *_DB_DIR，未配置时使用当前目录；进入运行前确认实际显示的目录及其写权限。

Current Host 默认在当前主机执行；选择 LSF Farm 后，等待队列与主机发现完成，再选择可提交的 Queue。直接运行 CLI backend 不会仅因 TOML 中写了 LSF 信息就自动提交，参见LSF 配置。

CAD 统一维护的工具默认项

文件用途
calibre-drc.svrf / calibre-lvs.svrf / calibre-xrc.svrfCalibre 各阶段的公共 SVRF 默认片段。
quantus.optionsQuantus 非 GUI 固定 options；按命令与输出模式分段。
quantus.launch.argsQuantus 启动参数；出厂许可证等待为 -lic_queue 1800。
starrc.optionsStarRC 抽取、耦合、数据库与文件输出默认项。
cdl.env / streamout.options公共 CDL 与 GDS 导出的默认设置。

CPU、温度、输出格式等 GUI 设置仍在表单中配置；PDK runset 与 tech 文件仍由工艺提供。CAD 调整默认文件前保留旧值，先用对应 generate 检查最终命令，再进行必要的工具验证。当次使用的默认文件快照与来源保存在运行目录的 log/flow-defaults/。
