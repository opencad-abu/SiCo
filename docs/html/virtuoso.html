03 / INTEGRATION

接入 Virtuoso

在启动 Virtuoso 之前加载 shell 环境，再由工程的 .cdsinit 注册 SiCo。加载完成后，CIW、Layout 和 Schematic 菜单提供相应工具入口。

配置工程 .cdsinit

打开个人工程实际使用的 .cdsinit，保留已有的 PDK 与项目初始化，将下列代码作为唯一的 SiCo 加载段。SICO_HOME 需由启动 shell 设置为有效的绝对路径。

SKILL · 工程 .cdsinit
let((sicoHome sicoSourceEntry sicoContextEntry)
  sicoHome=getShellEnvVar("SICO_HOME")
  unless(and(sicoHome strlen(sicoHome)>0
             substring(sicoHome 1 1)=="/" isDir(sicoHome))
    error("SICO_HOME must point to an absolute SiCo installation directory\n"))

  sicoSourceEntry=strcat(sicoHome "/scripts/sicoAutoLoad.il")
  if(isFile(sicoSourceEntry) then
    unless(load(sicoSourceEntry)
      error("SiCo source bootstrap did not load: %s\n" sicoSourceEntry))
  else
    sicoContextEntry=strcat(sicoHome "/tools/common/context/sicoBoot.cxt")
    unless(isFile(sicoContextEntry)
      error("SiCo bootstrap context is missing: %s\n" sicoContextEntry))
    ciwMenuInit()
    unless(loadContext(sicoContextEntry t)
      error("SiCo bootstrap context did not load: %s\n" sicoContextEntry))
    unless(callInitProc("sicoBoot")
      error("SiCo bootstrap initialization failed\n"))))

同一段初始化同时识别源码测试安装和二进制安装。它接入菜单和通信入口，不自动打开 SiCo 窗口，也不开始设计或验证任务。

启动并确认菜单

Bash · 从已配置环境的 shell 启动
cd /path/to/my/project
virtuoso
  1. 在 CIW 确认初始化没有报错，并看到 SiCo 菜单。
  2. 打开 SiCo → DRC 或 LVS，确认表单能显示当前工程库、规则候选与输出目录。
  3. 使用 SiCo → Silicon Copilot 打开主界面；终端形式的入口为 AI Assistant。

若菜单未出现，先在 CIW 查看 getShellEnvVar("SICO_HOME")。检查 Virtuoso 是否确实读取了该工程的 .cdsinit，以及启动命令是否使用了 -nocdsinit。站点可能通过自己的初始化链加载工程文件，应由该链保留一个 SiCo 加载入口。

独立 SiCo 关联 IC 会话

从同一工程 shell 执行 sico 后，在主窗口选择 通信 → 连接 CDNS-IC…，选择当前用户、本机、当前工程且已加载 SiCo 集成的 Virtuoso。首次执行 AI 任务前，按模型配置提供站点模型服务。

项目 SKILL 与 OA 配置

源码 bootstrap 支持 PROJ_CAD_HOME：指定项目 SKILL 目录后，在公共注册完成后递归加载严格以 .il 结尾的文件。.ils 由各模块入口按依赖加载。项目目录不能指向 SiCo 的 tools/。二进制安装的项目初始化由站点初始化链管理，不应假定这一源码自动加载机制存在。

OA 工具使用 CDS_LIB，未设置时表单采用 Virtuoso 当前工作目录的 cds.lib。需要导出 layout 时提供 TECH_LAYER_MAP；需要 CDL 器件定义时提供 CDL_HEADER_FILE。这些工艺文件必须匹配目标 library 的 PDK。

常见接入问题

现象检查与处理
找不到 sicoBoot.cxt核对完整安装、SICO_HOME 与 context 版本。二进制缺少 context 时重新部署匹配的安装。
连接列表里没有 Virtuoso检查当前用户、机器、工程路径及 SiCo 初始化是否成功；新的 shell 设置不会进入已经启动的 Virtuoso。
切换环境后仍显示旧规则或模型保存需要保留的配置，结束任务与工程服务，在新 shell 中重新启动 Virtuoso 和 SiCo。
Calibre 原生 OA view 无法导入RCE 的 Calibre View 还需站点 Calibre–Virtuoso 集成，提供 mgc_rve_load_setup_file。SiCo 菜单加载不能代替该工具集成。
提示 .sico 权限或其他用户所有进入自己的工程工作目录，核对状态根。多人共用安装不等于共用私有会话目录。
