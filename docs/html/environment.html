环境变量速查

查名称、取值和未设置时的行为。表格覆盖 SiCo 运行、站点集成及 CAD flow 的配置接口；自动传递项与旧名迁移另附索引。

这里的“默认”指当前代码在未设置时的行为，并非示例建议值。除有专门说明外，修改启动环境后需要重启对应进程；已经运行的工程服务不会重新读取 shell。构建脚本的编译开关和第三方软件完整变量集不属于本手册的运行配置范围。

安装、工程与公共入口

变量名可选值 / 格式默认 / 未设置行为作用
SICO_HOME有效绝对目录CLI 从自身入口定位；.cdsinit 要求显式设置唯一安装根；显式空值、无效目录或与入口不一致均报错。
SICO_PYTHONPython 可执行文件绝对路径二进制入口使用包内 Python；源码路径见说明共享解释器，优先于 SICO_PYTHON_ROOT。Assistant 要求 3.9.13。
SICO_PYTHON_ROOTPython 安装目录绝对路径二进制为 $SICO_HOME/runtime/python；源码站点配置SICO_PYTHON 未设置时使用其 bin/python3；显式空值报错。
SICO_SYSTEM_LD_LIBRARY_PATH冒号分隔的库目录；可空空SiCo Python 子进程的动态库搜索路径，通常含 Python/lib 与 SICO_HOME/lib。
SICO_TEMP_DIR.sico 状态目录；相对或绝对路径<启动目录>/.sico；空值视为未设置相对值在首次启动时固定为绝对路径；包含持久会话，不能作为普通缓存清空。
SICO_RUNTIME_TOOLStools 目录路径当前安装的 tools受保护后台 worker 的定位根；保持为 $SICO_HOME/tools。
PROJ_CAD_HOME项目 SKILL 目录不额外加载源码 bootstrap 在公共工具后递归加载 .il；不能指向 SiCo tools。
LOGO标题文本先读 LOGO，再 COMPANY，最后 SiCo部分 flow 表单标题前缀；历史文本 OCAD 被忽略。
COMPANY标题文本SiCoLOGO 未提供有效值时使用的表单标题前缀。
SICO_MENU_CACHE_DIR缓存目录$XDG_CACHE_HOME/sico；否则 $HOME/.cache/sico源码菜单生成数据的缓存位置。
SICO_RUNTIME_NO_MENU1；其他值为关闭此开关未设置1 跳过受保护工具菜单注册；后台集成使用，交互安装通常不设置。

常用优先级与空值

共享解释器：flow 专用覆盖 → SICO_PYTHON → SICO_PYTHON_ROOT/bin/python3 → 源码 flow 的 python3。Assistant 另有严格的 3.9.13 解释器检查，不能依赖 flow 的 PATH 回退。二进制入口使用包内 Python，应保持安装与 ABI 一致。

模型配置：显式配置文件 / SICO_PROVIDER_CONFIG 优先于环境模型设置；没有这些输入时，可读取工程默认 provider 文件。Profile 加载后的值覆盖表单环境初值，最后手动调整形成运行 TOML。

SICO_HOME、显式 SICO_PYTHON / SICO_PYTHON_ROOT 不能为空；SICO_TEMP_DIR 空值按未设置。不要假定所有变量都有相同空值语义。PROJECT_ROOT、PDK_ROOT、RCE_RUN_ROOT 等是用户在路径表达式中自定义的前缀，名称不由 SiCo 固定。
