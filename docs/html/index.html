第一次使用，按这个顺序

01加载站点环境02选择 SiCo 安装03接入 Virtuoso04配置并运行 flow

先加载项目的 Cadence、PDK 和许可证环境，再设置 SICO_HOME。进入自己的工程工作目录，启动 Virtuoso 或 sico。DRC、LVS、RCE 等独立工具可以直接使用，不要求先建立 AI 会话。

已有站点配置？ 从站点提供的 setup 脚本开始，在环境变量表核对项目差异，再阅读对应 flow。示例中的 /path/to/…、库名、工艺文件和模型名称均需替换为自己的实际配置。

先认清三个目录

目录保存什么使用方式
$SICO_HOME程序、运行库、公共默认配置由 CAD 管理；全套入口使用同一份安装。
个人工程下的 .sico持久会话、工程服务状态和运行辅助数据由 SiCo 创建和管理；包含历史记录，不当作临时缓存清空。
各 flow 的结果目录运行 TOML、工具命令、日志与输出通过表单的输出目录或各 *_DB_DIR 变量选择。

本手册说明当前主线的使用行为。二进制安装可能落后于主线；安装中的 RUNTIME-MANIFEST.json 用于识别实际代码版本。页面无需联网，浅色主题沿用 SiCo GUI 的红棕强调色，深色主题参考 AIVI / oaplg 家族风格。
