1. 定义与范围

电路模板是带固定内容身份、来源证据、明确电气拓扑、可选图形资产及受控复用规则的电路知识单元。 模板描述可参考的结构、接口与布局关系；目标电路另以完整 circuit_spec 表达实际器件、参数和连接。

本版覆盖原理图模板的抽取、存储、检索、匹配、适配、目标创建及验收；symbol 和物理 layout 可作为独立资产附带。物理版图重建、DRC/LVS、跨工艺电气等价和性能仿真不属于模板资格本身。 RC/opamp 等示例生成器、仿真 recipe、任意可执行脚本不因名称含 template 就属于本规范。

必须区分以下对象，不得用一个“模板可用”标志代替：

对象／结论 含义 尚不能证明
原始采集证据 一次只读采集的事实及缺失项，可供复核 拓扑完整、允许复用
参考模板 可读取的归一化记录，可按已支持能力查看或精确消费 任意修改拓扑、跨工艺直接创建
合格复用模板 源证据满足指定能力，复用契约合法且可重新验证 目标 PDK、参数、几何已就绪
目标准备计划 选定模板和明确目标完成映射、适配与几何检查 已完成现场创建预检或 OA 写入
已创建电路 创建、保存、重开及实际回读达到所声明的验收范围 视觉、仿真、物理版图均合格

上述是语义区分，不要求新增一套重复状态字段；现有 qualification、prepare、创建和验收回执 各自承担相应职责。模板缺少某资产，只阻塞依赖该资产的操作。

2. 单一权威与维度

信息 权威归属 约束
已保存的源连接 topology 器件端子、网络、端口只维护一份电气图
源视图图形与位置 assets.schematic/symbol/layout 按 topology ID 关联，不按截图推导连接
复用权限与硬约束 reuse_contract 引用已有器件／端点，不再复制电气图
源类别及资格依据 分类证据、源观察、qualification 明确来源与适用修订；可重新校验
目标器件、参数、连接 目标 circuit_spec 不由模板源参数、缓存或隐含规则覆盖
目标工艺使用规则 已发布的 SiCo PDK 数据及有效绑定 模板不维护第二套 CDF 可写性和参数范围
本次复用对应关系 template_use 绑定固定模板、目标意图和适配回执，可重验
查询摘要、索引、缓存 权威内容的派生数据 可删除重建，不成为人工维护入口

category（digital/analog/reference）、granularity（atomic/block/subsystem/ip）、 detail_level（L1/L2/L3）、tier（private/project/builtin）互相独立，均不授予创建资格。 未确定的粒度可以保留未知；不能以目录名或器件数猜测功能层级。

3. 记录内容与电气语义

原理图参考记录至少包含版本、固定引用、来源／capture 摘要、资产覆盖、topology、缺口和派生摘要。 只有 symbol/layout 的有效采集可作为相应资产参考保存，但不得宣称具有原理图复用资格。 字段拼写沿用现有 schema；本表规定逻辑责任，不要求另造平行文件或重复字段。

内容 必备语义
身份与版本 schema_version、rule_version、template_ref；capture 版本与 catalog 兼容版本单独解释
来源 library/cell/view、采集身份、依赖与内容摘要；原始解析路径只作受控证据
器件 唯一 ID、类别、role、已观察的 master/端子清单、分类依据；源实例名属于追溯信息
网络 唯一 ID、名称、位宽、明确 global/local 语义和 sig_type
端点与端口 器件 ID＋端子名到网络的连接；外部端口的名称、方向、位宽与网络
覆盖与缺口 哪些事实已采集、缺失、未知、不适用或不受当前能力支持，保留具体对象与理由
复用契约 对合格 v3 必备，明确 core、optional、boundary、规则及布局约束

未知、空集合、明确不存在和不适用必须区分。未知 global 不能默认为 local；未知器件类别 不能推定为允许；缺少端点不能以“通常如此”的连线补齐。重复 ID、悬空引用、冲突分类必须拒绝。

项目器件分类必须有覆盖实际源对象的证据；名称、端子外观及所属 PDK 名称不能充当分类证明。 basic/analogLib 图元的特殊处理须有已解析的安装库身份及 master 类型证据，不能只看名字。 几何分组、同行、镜像和相似名称不证明功能分组、电气匹配、D/S 可交换或可删除权限。

当前基线的 v3 复用能力限定 direct-level、已确认类别、完整连接的标量电路。 层级、继承连接、mosaic、未展开 bus、未验证 master 或不完整源几何须按能力明确拒绝／报告； 保留参考记录不等于通过复用验收。后续扩展须新增能力及正反例，不能仅清除 gap 标记。

4. 几何、参数与内容详略

新生成的归一化坐标使用源数据库整数 DBU 的相对位置，记录单位换算、锚点与舍入缺口。 source anchor 的绝对位置只用于追溯；旧 v1 的 user-unit 坐标按旧版本解释，不静默重标。 目标位置、占用框、pin anchor、间距和布线必须依据目标 master、有效参数与目标网格重算。 wire 的归属以已保存的网络及端点证据为准；线条视觉相交不自动表示电气连接。

内容层级 保存目的 限制
原始记录 源事实、追溯和重新验证 私有证据，不能等同已经脱敏的共享投影
L1 抽象器件类别、接口、拓扑及相对关系／风格 不含源 master、原始坐标、尺寸或私有路径
L2 L1 加明确 PDK master 身份和相对原理图几何 不含源数值 sizing；工艺身份仍需按访问范围控制
L3 L2 加源器件上观察到的物理参数 数值只作参考，不表示适合目标 PDK 或可以直接赋值

投影必须按字段白名单产生，移除原始 SKILL 文本、源实例名、绝对库路径及私有 wire 原始证据。 投影保存固定源引用和 capture 摘要用于受控追溯；不得因脱敏丢掉电气限制却仍宣称合格。 历史 SQLite 投影接口仍拒绝直接投影 v3；标准 JSON raw 的 L1/L2/L3 发布已通过独立入口接入， 参见标准分层发布。各层级独立计算资格，不自动提升为 legacy v3。

源属性、表达式和动态文字只作数据，不执行源表达式或任意 callback。 W/L、指宽／总宽、nf/fingers、m、segW/segL 等不可跨工艺按同名推定等价。 目标参数以目标 PDK 的参数规则和本次 spec 为准；源参数别名表不能成为跨 PDK 写入白名单。 物理输入与派生值分工遵守PDK 数据标准。

5. 身份、存储与目录

template_ref 使用既有 tpl_＋64 位十六进制摘要格式；目录位置不充当模板身份。 v1/v2 保留各自历史算法，v3 沿用版本化 canonical 内容算法，排除自引用和派生 summary。 摘要编码固定 UTF-8、排序键、有限数值；不得改变旧引用的算法或把 cad.* 协议前缀机械改名。 内容、分类证据或复用许可改变必须产生新引用。复制同一内容到另一目录不改变引用； 重新采集导致 provenance 改变时可产生新引用，不能仅凭拓扑相同强行复用旧身份。

来源 当前位置 写入边界
private <workspace>/.sico/ai/circuit_templates 新抽取及私有预览的工作区入口
project $SICO_CIRCUIT_TEMPLATES_DIR SiCo 读取；由用户／CAD／IT 放置
builtin <SiCo>/tools/ai/reference/circuit_templates（若存在） 只读参考；不表示正式软件包必须附带

状态目录只经统一 sicostate 解析。旧 .cad 只读，写入前按既有迁移器激活； .cad/.sico 同时存在时遵守激活检查，不自行合并。旧 reference/circuit-templates 作为已支持的兼容读取布局，不产生第二个写入目标。新产品配置使用 SICO 环境变量。

当前兼容实现读取：根 catalog.sqlite3，或 catalogs/*.sqlite3 的一级成员； captures/ 和 previews/ 是辅助证据／可重建产物，不是普通共享消费的必要条件。 新采集数据拟改用上述扁平 JSON 标准，SQLite 保留为 legacy 输入或可重建索引，不能双份人工维护。 离线补全若依赖 retained capture，必须明确其必要性及缺失反馈。

同 ref 同内容跨来源合并并保留全部来源；同 ref 不同内容必须报冲突。 同名 cell 的不同 ref 分别保留。目录不存在／空与损坏／不可读必须区分。 来源偏好 private → project → builtin 只在质量比较后使用，不能覆盖内容冲突或硬约束。 数据读取须验证普通文件、边界、SQLite 状态、成员稳定性及内容一致性，拒绝越界软链接与活动 WAL/journal。

snapshot_ref 表示一次目录内容观察；record digest 表示完整记录内容；template_ref 表示版本化模板身份。三者不得互相替代，也不代表审批或电路性能认证。

6. 抽取与资格补齐

  1. 明确源 library/cell/view、采集资产及必要分类证据，只读采集，不保存或改写源 OA。
  2. 校验 capture 完整性、来源、依赖和电气事实；构造参考记录并保留具体缺口。
  3. 要求可复用时，通过同一 extract_circuit_templates 显式选择 reuse.mode=whole/core。 whole 保护所有器件和端点；core 由源实例名声明核心、完整可选组与外围边界。
  4. 权威构造器推导内部 ID、边界连接和删除后的网／端口，再验证分类、源资格和契约。
  5. 原子写入工作区私有库，不覆盖既有不同内容；返回固定 ref、资格范围和缺口。
  6. 缺失分类等可离线补齐项优先使用保存的 ref 和 continuation；源事实变更或无法补证才重新采集。

省略 reuse 保持参考抽取语义。复用失败但参考有效时，可保留参考；必须返回失败状态、 具体原因及 reuse.template_ref=null，不能将顶层参考 ref 当作合格复用 ref。 补齐分类不得覆盖冲突证据、抹掉层级或虚构端点；新契约产生新引用，保留基线追溯。 qualification 必须绑定源事实与摘要并可重新计算，不能以手工置 true 替代验证。

7. 复用契约与适配

core 与 optional groups 必须互斥并覆盖全部电气器件；core_connections 保护全部核心端子。 每个外围边界必须声明核心端点、允许的外接器件类别及连接数量范围。 数量按非核心端点计算，包含保留的可选器件，不能误按外围器件个数计算。

允许的改变只限已安装且版本固定的规则：

规则 要求
rename 局部网络／端口显式改名；保留完整对应与方向，不由对称性推断交换
omit_optional_group 仅删除明确允许的完整组，检查被删除的网、端口及残余连接
add_boundary_group 新增器件通过允许边界接入，不改变受保护核心内部连接

每条规则同时满足模板声明和本次目标授权，核对 id、version、implementation_digest。 已有用户决定和有效规则选择可以复用；“显式授权”不要求每次重新询问。 目标 spec 必须完整表达适配结果，不能仅传“从模板删掉若干器件”作为隐藏意图。 当前实现最多省略 8 个完整组；新增限一个连通外围组，省略与新增不能在同次适配混用。 改变这些界限必须有版本化能力和验证，不通过扩大数组或预算暗中开放。

禁止隐式合并／拆分网、交换差分或 D/S 端子、修改核心连接或丢掉 global/supply/ground 语义。 历史精确适配中的 net_scope_map 仅按该入口已验证条件使用，不扩大为通用转换许可。 适配回执必须保留完整映射、规则、差异与输入／输出摘要；下游重验回执，不只信任摘要字符串。

8. 检索与目标准备

推荐入口为 prepare_circuit_template_plan；query/get 用于调查和按需选取详情， match 用于明确的拓扑比较，prepare_template_circuit 保留已支持的 legacy 精确适配。 新工作流共用一套匹配、适配和几何验证器，不新建第二个创建后端。

目标准备提交完整 spec、固定候选或明确搜索范围、必要映射与规则，另选以下互斥输入：

  • binding_refs，或完整 bindings + geometry。
  • placement（含明确 routing 选择），或显式 layout。

binding、内部 ID、digest、callback 元数据由工具取得和保留；不让用户手工抄录。 先检查硬条件，再比较适配代价、覆盖与来源。指纹、索引命中或相似度只能筛候选。 对称映射歧义返回 needs_mapping；未知不按硬拒绝处理，也不默认交换端口。

结果 必须表达
ready_for_creation_prepare 固定候选、完整且验证通过的 plan、摘要及快照；尚须现场创建预检
needs_selection/mapping/adaptation/binding/geometry 具体对象、缺项及下一步；plan=null
no_match 已完成本次范围内所有候选判定且全部不满足
inconclusive 预算耗尽或结果未知；保留已检查／剩余／未知量和停止原因；plan=null
unavailable/invalid_request 环境／数据不可用或输入错误；不降级为空库、不生成计划

固定 ref 或 first_eligible 要求 return_alternatives=0；first_eligible 不宣称全局最佳。 只有 ready 可携带完整 plan；响应超限不能裁掉验证输入后仍称 ready。 prepare 结束前及进入创建链时复核所需内容；成员或依赖改变则失效，不能执行期间自动改绑 latest。 缓存只保存可重建纯值，键覆盖内容、规则、目标与依赖版本；命中仍做权威重验，关闭后语义等价。 ready plan 缓存不保存 OA 句柄、写入授权或现场成功回执。

9. PDK、创建、symbol 与 TB

正常设计消费已发布 PDK 包的使用资格与参数规则；模板缺项不得导致反复重新发现相同 PDK 规则。 仅真实依赖改变、现场冲突或未知行为进入维护／针对性 probe，沿用 PDK 标准的边界。 实际目标仍须经所选 PDK 初始化、受支持 CDF/callback、有效参数与真实几何检查。 源模板中的空参数或同名物理量不构成绕过 PDK 必备赋值的许可。

推荐创建链：目标准备 → prepare_circuit_creation → SiCo 既有执行入口 → inspect／回读。 实际写入前重新核对任务、目标动作、来源和摘要；已有有效目标决定及呈现方式继续使用。 用户既有非空视图须沿已确认的继续／备份后替换流程处理，不能默认覆盖；只读源、PDK 和 安装库保持保护。目标身份按实际解析路径和依赖判断，不因 library 改名解除保护。 未知写入结果先查原操作，禁止换 request_id 盲目重放；保留失败阶段、引用和部分目标证据。

创建完成至少要求 schCheck、逐端点连接／有效参数／几何回读、保存重开及幂等核对。 明确选择的 stub 与失败 fallback 必须分别报告；fallback 不得冒称连续布线。 外部 pin 默认独立 stub 的既有策略保持；只有明确选择才做连续端口布线。 图面质量须检查实际原理图截图，PNG/SVG 导出成功或 schCheck 通过均不自动证明视觉合格。

为源设计单元补建缺失 symbol 时，沿用现有明确许可与接口校验，不改写其 schematic。 symbol 预览默认 style=auto：有可用捕获轮廓时使用 template_outline；不能使用轮廓时 返回 rectangular_module 并在 fallback_reason 说明原因。轮廓渲染不能复现的源文字标注 默认拒绝；显式 label_policy=drop 可省略并在 dropped_labels 逐项报告，二者都不静默 丢失信息。label_policy=preserve 可保留普通文字和 cdsParam(...) 占位符的位置、 justify、orient、font、height，并以非执行标签重绘；cdsParam 不执行表达式。包含 条件表达式或未知 ILLabel 的动态标注明确拒绝，不采用求值或静默替换。 常见符号可使用 symbol_family：私有 .cad/ai/circuit_templates/symbol_families/<family_ref>.json 保存一份规范化的 body/stub 几何和 terminal slots；目标 schematic 通过 slot_map 把端口绑定到 slots， 不复制源 cellview。family 记录版本化为 sico.symbol.family.v1，目标端子方向/宽度 必须与 slot 一致；找不到绑定或 family 不可用时明确报错，不回退为静默改名。 为 DUT 创建 TB 前，检查同一 library/cell 的 symbol：已有则校验复用；缺失则根据已保存 schematic 接口创建、保存并校验。接口不一致或创建失败时停止 TB，不以展开内部器件替代 DUT。 辅助测试／probe 只在当前工作区 SicoTest 后台创建，不覆盖视图，不打开或抬升编辑器； 路径冲突须报告。用户交付视图沿用已确认的呈现方式。schCreateWire routeMethod 只允许 direct/full。

10. 有界读取与接口

默认返回摘要、计数、覆盖和固定引用；topology、relations、parameters、资产详情按 section/entity 分页。 每个有界列表保留总数、返回数及省略／续页信息，不以删除硬约束满足预算。 原始 capture、长 CDF 和 SVG 正文不进入普通模型上下文；图形通过私有 artifact 引用交付。

本草案先固定有界原则；当前实现的兼容参数如下，不把 PDK 接口的 16 KiB 上限套到模板接口：

项目 当前基线
query 条数 默认 10，最多 30
get 详情条数 默认 100，最多 200；仍受总响应预算约束
模板／prepare 完整响应 最多 90,000 UTF-8 JSON 字节
capture 最多 64 MiB
v3 topology 最多 64 器件、256 网、128 端口、每器件 64 端子；完整匹配图还受 512 节点限制
检索默认预算 500 ms、50,000 states；整体 prepare 默认 5,000 ms

这些是接受上限，不是延迟承诺。超预算须返回可区分的未知／超限结果，不放宽正确性或隐式扩大搜索。 若将来压缩公共接口，必须同时定义分页、完整计划传递及兼容迁移，不能只减少数值上限。

11. 验收与历史迁移

验收面 最低证据
数据与身份 schema、引用、摘要、ID／引用一致性、summary 一致性、不可变冲突、目录移动后固定引用
源资格 分类覆盖、源依赖、完整端点、网语义；unknown、层级、继承、缺几何等反例不得被提升
复用契约 核心保护、组完整性、边界与双重授权；缺规则、篡改映射、越界修改必须拒绝
搜索与准备 完整基线／索引对照、歧义、no_match 与 inconclusive 区分、缓存等价及内容变化失效
创建生命周期 实际 PDK/CDF、目标保护、保存重开、逐端点及参数回读、未知写入恢复与幂等
图面与其他资格 实际截图检查；视觉、仿真、物理验证分别报告，未执行项明确未验证

验收报告记录版本、输入摘要、范围、执行环境、结果、未完成项与私有证据引用。 合成变体不能计作独立真实设计；Agent 图像审阅不能替代人工电路专家验收。 某一个案例通过不构成全部模板、全部 PDK 或全部图面合格。

旧 v1/v2 及历史结构型 v3 按既有能力只读兼容；格式可读与资格通过分别检查。 升级不得仅改 schema 标记或补 true：补证据、重跑资格／契约验证、产生新 ref，并保留旧引用。 符合性按具体能力登记，不能要求所有历史参考立即具备所有资产。 legacy 入口退出条件为消费者迁移完成、固定引用重放与兼容验收通过，并在正式版本中明确宣布。

模板目录复制与文件版本由用户／CAD／IT 管理；本规范不新增审批、发布、NFS 或版本管理服务。 内部 catalog writer 的 publish 仅指原子落盘，不代表外部发行授权。 共享、脱敏与运行发行是不同边界；本规范及模板数据不因合规而自动进入软件发行包， 正式分发仍遵守运行发行政策。
