环境接口附录

查阅自动传递的进程变量与已登记的旧名。日常安装从环境变量速查开始；此处用来识别日志中的名称和排查遗留配置。

以下运行字段由启动器、宿主或任务产生。除标明可覆盖的项目外，没有可供用户统一设置的固定值；会话端口、token、PID 和任务路径不能复制到另一会话。

保留与隔离的名称

CDS_MPS_* 是 Cadence 多进程会话标识。MTS 与独立 worker 启动时清除这些宿主标识，避免源项目加入目标 Virtuoso 会话。MTS_NETLISTOR_TARGET_CDSLIB、SICO_TARGET_CDSLIB、CADENCE_TARGET_CDSLIB 是隔离边界会清除的目标选择遗留字段，不是项目配置入口。

SICO_SOCKET / SICO_TOKEN 也是 PDK worker 会清除的旧会话字段。VIRTUOSO_CONTEXT_BUILD、RCE_VIRTUOSO 以及终端 build/smoke 脚本变量属于编译或验收工具，不应进入日常安装环境。PROJ_AMS_DB_DIR 是 AIVW 输出布局中沿用的站点术语，具体路径由验证工作区配置提供，不是 DRC/LVS/RCE/MTS 的输出变量。
